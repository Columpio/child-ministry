# Child Ministry — уроки по Библии

Интерактивный сайт для занятий по Библии с детьми: видео, слайды и вопросы по каждому уроку.

## Сайт

Открыть задеплоенную версию:

**[https://columpio.github.io/child-ministry/](https://columpio.github.io/child-ministry/)**

## Локальный запуск

```bash
cd site
npm install
npm run dev
```

Сайт собирается и публикуется автоматически через GitHub Pages при каждом push в ветку `main`.
